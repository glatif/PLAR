## Citation convention

| Pattern | Meaning |
|---|---|
| `[EMAIL]` | The stakeholder email (`Resources/project-email.md`). |
| `[P1-B p.22 "Heading"]` | Source P1-B, **printed** page 22, under the quoted heading. |
| `[P2-B PDF p.9]` | PDF page 9, for files with no printed page numbers. |
| `[P1-C §"5. Numeracy"]` | Word documents have no fixed pages, so the heading or section is cited. |
| `[P2-A step 7]` | Numbered step in a "Steps" document. |

**Page-number notes**

- **P1-B Assessor Handbook:** printed page = PDF page − 5. Citations use the printed number, which matches the handbook's own table of contents.
- **P2-I Student Handbook:** printed page = PDF page − 1. Citations use the printed number.
- **Scanned files (OCR):** P2-I, P2-M and P1-SP1 are image-only PDFs (made in Canva or scanned). We read them with OCR, so check exact wording against the original before quoting it to stakeholders.

## Handling rules for these sources

- The sources contain confidential student material (P1-SP*, P2-B, P2-C). Do not copy student details into the platform, test data or prompts without agreement. See [10-principles-and-constraints.md](10-principles-and-constraints.md#confidentiality-and-privacy).
- One source contains an access credential for the readiness questionnaire. It is **deliberately left out** of this documentation.
- Per-step effort estimates in the sources are **deliberately left out**, at the project lead's request. Deadlines that work as process rules (such as the 24-week portfolio window or the reminder schedule) are kept, because features depend on them.
